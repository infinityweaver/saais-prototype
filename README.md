# SAAIS clickable prototype

A clickable prototype of **SAAIS** (Student Academic Advising Information System) for the Department of Computer Science and Technology, Visayas State University.

**Try it:** https://infinityweaver.github.io/saais-prototype/

- Use the strip at the top to switch between roles (student, adviser, Department Head, staff, Dean, admin).
- It works on a PC or a phone.
- All names, student numbers, course codes and grades are **sample data**, not real records.
- Nothing you do is saved. Reloading the page resets it.

**Style guide:** https://infinityweaver.github.io/saais-prototype/designstyle/

The SAAIS look (VSU brand colors, Montserrat and Roboto, status badges, buttons, form inputs, cards, tables, header and menu) built from the app's real React components. It is a static copy of the app's `/styleguide` page, with sample data only. Updates arrive as pull requests on the `designstyle` branch.

This repo is published automatically from the main SAAIS project. Do not edit it here; changes are overwritten.
